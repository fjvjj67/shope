# نظام إدارة الطلبات والشحن — AZAWI

**الموقع:** https://fjvjj67.github.io/shope/

صفحة واحدة لإدارة الطلبات والمصانع ومحفظة شركات الشحن (كوانزو / ايو)، منشورة على GitHub Pages،
وتحفظ بياناتها في Supabase (قاعدة مشتركة بين كل الأجهزة، مع تحديث مباشر).

## شنو بيه
- **حسابين منفصلين بالكامل:** كوانزو وايو، تبدّل بينهم بزر واحد فوك.
- **محفظة شركة الشحن بالرمبي:** أرسلت فلوس (دينار أو دولار ← رمبي، مع سعر التحويل)، حوالات بالانتظار، صورة الوصل، دفعوا لمصنع (كامل/جزئي)، شحن ونقل، وكشف حساب.
- **الطلبات:** إضافة المصنع من نموذج الطلب نفسه، مواعيد التجهيز، مواعيد الدفعات وتسديدها.
- **الشحنات:** نموذج مختصر وأزرار سريعة (انطلقت / وصلت).
- **Excel يدوي** لكل حساب (مع الصور وكشف شركة الشحن) ونسخة احتياطية JSON.
- يشتغل بالصين بدون Google: الخطوط والمكتبات كلها من نفس الموقع.

## الصلاحيات
| الدور | ماذا يستطيع |
|---|---|
| **مدير** (admin) | كل شيء |
| **موظف** (staff) | يشوف كل البيانات ويضيف ويعدّل الطلبات والشحنات بس. بدون فلوس ولا حذف |
| **موقوف** (pending) | ما يشوف أي شي |

- الدخول برمز: رمز المدير أو رمز الموظف. الرموز محفوظة مشفّرة في Supabase فقط.
- الصلاحيات مطبّقة داخل قاعدة البيانات (Row Level Security)، فما تنتجاوز من المتصفح.

## الملفات
- `index.html` — التطبيق كامل. `lib/` و`fonts/` — المكتبات والخطوط.
- `supabase/` — الجداول والصلاحيات (`05_trade_v2.sql` آخر تحديث).
