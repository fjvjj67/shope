# نظام إدارة الطلبات والشحن — AZAWI

**الموقع:** https://fjvjj67.github.io/shope/

نظام لإدارة طلبات مصانع الصين، والفلوس الي عند شركات الشحن، والشحنات. يشتغل من الهاتف واللابتوب،
والبيانات محفوظة بقاعدة بيانات واحدة (Supabase) تتحدّث على كل الأجهزة بنفس اللحظة.

## شنو بيه
- **حسابين منفصلين:** كوانزو وايو. كل حساب بيه مصانعه وطلباته وفلوسه وشركة الشحن مالته.
- **محفظة شركة الشحن بالرمبي:** أرسلت فلوس (دينار أو دولار، والنظام يحسب سعر اليوان)، حوالات بالانتظار، صورة الوصل، دفعوا لمصنع، شحن ونقل، كشف حساب.
- **الطلبات والدفعات:** إضافة المصنع من نموذج الطلب، مواعيد التجهيز، الدفعات المجدولة وتسديدها، تنبيهات التأخير.
- **الشحنات:** انطلقت / وصلت بضغطة.
- **Excel يدوي** لكل حساب (مع الصور وكشف شركة الشحن)، ونسخة احتياطية JSON.
- **المظهر:** غامق أو أبيض نظيف (من صفحة الملفات والنسخ، كل جهاز يتذكر اختياره).

## المستخدمين والصلاحيات
| الدور | يشوف | يكدر |
|---|---|---|
| **مدير** (رمز المدير) | الحسابين | كلشي، والحذف، والمستخدمين |
| **موظف** (رمز الموظف) | **ايو بس**، والشاشة **بالصيني** | يضيف ويعدّل كلشي بايو. **ما يحذف** |
| **موقوف** | ولا شي | ولا شي |

- الحماية داخل قاعدة البيانات نفسها (Row Level Security): الموظف ما يكدر يشوف كوانزو ولا يحذف حتى لو حاول من خارج الموقع.
- كل تعديل ينحفظ بسجل تاريخي (`docs_history`)، فأي رقم يتغيّر بالغلط يرجع.
- حساب الموظف ولغته محددين بجدول `profiles` (العمودين `company` و `lang`). لتغيير حساب الموظف: غيّر `company` إلى `main` (كوانزو) أو `yiwu` (ايو).

## اللغتين (عربي ⇄ صيني)
- **الشاشة:** الموظف يشوف كل الأزرار والعناوين بالصيني (القاموس بملف `js/i18n-zh-dict.js`).
- **النصوص المكتوبة:** الي يكتبه الموظف بالصيني (اسم مصنع، ملاحظة، اسم منتج) يطلعلك **بالعربي**، والي تكتبه إنت يطلعله **بالصيني**. الأصل ما يتغيّر بقاعدة البيانات.
  الترجمة تصير من خدمة `translate` على Supabase، وكل جملة تنترجم مرة وحدة وتنحفظ.
  تكدر توقفها لكل جهاز من صفحة **الملفات والنسخ ← الترجمة التلقائية**.
- ملف Excel يكتب النص الأصلي ووياه الترجمة بين قوسين.

## الربط بين الأجهزة
- أي تعديل يوصل لباقي الأجهزة فوراً (Realtime).
- إذا الهاتف نام أو انقطع الإنترنت: أول ما يرجع، النظام يعيد تحميل البيانات تلقائياً، وكل دقيقتين يتأكد.
- إذا ماكو إنترنت يطلعلك تنبيه إن التعديلات ما تنحفظ.

## تشغيله بالصين
- الخطوط والمكتبات كلها من نفس الموقع (بدون Google).
- GitHub Pages و Supabase مرات بطيئين أو محجوبين بالصين بدون VPN. إذا صارت مشكلة: VPN، أو ننقل الموقع لاستضافة ثانية.
