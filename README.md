# نظام إدارة الطلبات والشحن — AZAWI

**الموقع:** https://fjvjj67.github.io/shope/

صفحة واحدة (`index.html`) لإدارة المصانع والطلبات والدفعات والشحنات وشركات الشحن، منشورة على GitHub Pages،
وتحفظ بياناتها في Supabase (قاعدة بيانات مشتركة بين كل الأجهزة، مع تحديث مباشر).

## الصلاحيات

| الدور | ماذا يستطيع |
|---|---|
| **مدير** (admin) | كل شيء: الدفعات، المصانع، شركات الشحن، الحذف، الاستعادة، إدارة المستخدمين |
| **موظف** (staff) | يرى كل البيانات، ويضيف ويعدّل **الطلبات والشحنات** فقط. لا حذف |
| **بانتظار الموافقة** (pending) | لا يرى أي بيانات حتى يفعّله المدير |

- الدخول برمز واحد: رمز المدير يفتح حساب المدير، ورمز الموظف يفتح حساب الموظف المشترك.
  الرموز محفوظة مشفّرة في Supabase فقط، وليست في هذا المستودع.
- المدير يستطيع إيقاف حساب الموظف أو إعادة تفعيله من صفحة **المستخدمون**.
- الصلاحيات مطبّقة داخل قاعدة البيانات نفسها (Row Level Security) وليس في الواجهة فقط،
  فلا يمكن تجاوزها من المتصفح.

## نسخة Z التجريبية

**الرابط:** https://fjvjj67.github.io/shope/z/

نفس النظام ونفس قاعدة البيانات ونفس رموز الدخول، بتصميم Z (كارت بني غامق، كروت بيضاء، شريط تنقل بيضاوي على الموبايل، قائمة جانبية تنطوي على اللابتوب) مع إضافات:

- **شرط الدفع لكل طلب** (30/70، 40/60، 50/50، 100% مقدماً) وجدولة الدفعات تلقائياً حسب الشرط.
- **إيصال الحوالة** مع كل دفعة (صورة أو PDF، تنضغط الصورة تلقائياً). يحتاج تطبيق `supabase/04_receipts.sql` مرة وحدة.
- **تنبيه قبل الشحن** إذا الطلب عليه مبلغ غير مسدّد.
- **كشف حساب المصنع** مع حركة الدفعات وتصديره Excel.
- **بحث سريع** بـ Ctrl+K، **رسم المدفوع حسب الشهر**، **الوضع الداكن**، وانتقالات ناعمة بين الصفحات.
- على اللابتوب تفاصيل الطلب تنفتح كلوحة جانبية.

النسخة الأصلية (`index.html`) ما تغيّرت. لما تعتمد Z، ننقل `z/index.html` مكان الأصلية.

## الملفات

- `index.html` — التطبيق كاملاً.
- `supabase/schema.sql` — الجداول والصلاحيات (مطبّقة على مشروع Supabase).
